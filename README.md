# 🎮 XstreamPad - Xbox Style Controller for Airtel Xstream & Roblox TV

Turn your Android phone into an authentic **Xbox Wireless Controller** for playing **Roblox** and games on your **Airtel Xstream Setup Box & Android TV**.

---

## 📱 How to Download the Android APK from GitHub Releases

We have configured an automated GitHub Actions pipeline that compiles the Android APK and publishes it to the **Releases** section whenever you push this repository to GitHub!

### Step 1: Push your code to GitHub
If you haven't pushed yet, run:
```bash
git add .
git commit -m "feat: Xbox style gamepad and APK build"
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main
```

### Step 2: Download the APK from the "Releases" Section
1. Open your repository on GitHub in your web browser.
2. In the right-hand sidebar, click on **Releases** (or navigate to `https://github.com/<YOUR-USERNAME>/<YOUR-REPO>/releases`).
3. You will see the latest release: **`XstreamPad Xbox Controller APK v1.0.x`**.
4. Under **Assets**, click on **`XstreamPad-Xbox-Roblox.apk`** to download it directly to your phone.

### Step 3: Install on your Android Phone
1. On your phone, tap the downloaded `XstreamPad-Xbox-Roblox.apk`.
2. When prompted, allow **"Install from unknown sources"** for your browser or file manager.
3. Tap **Install** and open **XstreamPad**!

## 🕹️ Xbox Controller Features
- **Authentic Asymmetric Thumbsticks**:
  - **Upper-Left Stick (LS)**: 360° analog character movement (WASD) with customizable deadzones.
  - **Lower-Right Stick (RS)**: 360° camera orbit with smooth sensitivity curves.
  - **Clickable Sticks**: L3 (Crouch toggle) and R3 (First person toggle).
- **Official Xbox Colored ABXY Cluster** (Upper-Right):
  - **A (Green)**: Primary Jump (Roblox Spacebar) with extra-wide obby jump pad.
  - **B (Red)**: Back / Cancel / Crouch.
  - **X (Blue)**: Interact / Pick up (`E` key).
  - **Y (Yellow)**: Backpack / Inventory (` key).
- **Xbox D-Pad** (Lower-Left):
  - Faceted 8-way metallic hybrid disc for quick Roblox tool slot selection (1, 2, 3, 4).
- **Xbox Bumpers & Triggers**:
  - **LB**: Sprint / Fast Walk.
  - **LT**: Contoured trigger with analog squeeze depth (Crouch / Sneak).
  - **RB**: Primary Action / Tool Use (Mouse Click).
  - **RT**: Heavy Attack / Turbo Action.
- **Center Xbox Console**:
  - **Glowing Xbox Nexus / Guide Button**: Central illuminated sphere for dashboard & menu.
  - **View Button (`⧉`)**: Leaderboard / Player list (Tab).
  - **Menu Button (`☰`)**: Roblox ESC menu / Settings.
  - **Share / Emote Button (`⮝`)**: Instant wheel for `/e dance`, `/e wave`, `/e cheer`, `/reset`.

## 📺 How to Connect to Airtel Xstream Setup Box
1. Open any browser (like **TV Bro**, **JioPages**, or **Chrome**) on your Airtel Xstream box.
2. Navigate to your app URL.
3. Switch to **TV Screen Mode** (it shows a large QR code and a 4-letter PIN, e.g. `X7R2`).
4. On your phone, point your camera at the TV QR code or enter the 4-letter PIN.
5. Your phone will instantly connect with ultra-low latency WebRTC (< 10ms) and you can play right away!
